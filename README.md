# IMDb Movies EDA Project

## Project Overview
This project performs Exploratory Data Analysis (EDA) on the IMDb Top 1000 Movies dataset using Python.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Analysis Performed
- Data Cleaning
- Missing Value Analysis
- Top 10 Movies by IMDb Rating
- IMDb Rating Distribution
- Genre Analysis
- Director Analysis
- Correlation Analysis
- Meta Score vs IMDb Rating

## Key Insights
- The Shawshank Redemption has the highest IMDb rating.
- Drama is the most common genre.
- Steven Spielberg has the highest number of movies in the dataset.
- IMDb Rating and Meta Score show a weak positive correlation.
